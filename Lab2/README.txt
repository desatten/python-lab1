Проект: Lab2_Task2
Файл запуска: main.py

Лабораторная работа №2, задание 2, вариант рисунка 2.
Программа получает X, Y и R, после чего проверяет, находится ли точка
в одной из двух серых частей рисунка: четверти круга в верхней левой
части координатной плоскости или треугольнике ниже оси X.
Граница области включается. Радиус R должен быть положительным.
Запуск: python main.py

№1 X: -1; Y: 1; R: 2 попадает
№2 X: -2; Y: 0; R:2 попадает
№3 X: 1; Y: 1; R:2 не попадает
№4 X: 1; Y: -0.5; R:2 попадает
№5 X: 0; Y: -2; R:2 не попадает
